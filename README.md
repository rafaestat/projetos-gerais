# Projetos Gerais

Dois joguinhos web publicados no mesmo GitHub Pages, cada um no seu endereço.

| Jogo | Link | Pasta |
| --- | --- | --- |
| 🚗 **Carrinho da Lara** | https://rafaestat.github.io/projetos-gerais/ | raiz (`/`) |
| 🕯️ **Ateliê Essenzia** (simulador de ASMR) | https://rafaestat.github.io/projetos-gerais/atelie/ | [`atelie/`](atelie/) |

Os dois são abertos direto no navegador (celular, tablet ou computador), sem instalar nada.
O deploy é automático: cada atualização na branch principal republica o site.

> O **Ateliê Essenzia** fica melhor com fones de ouvido — o áudio é espacial e
> acompanha o movimento das mãos. Veja detalhes em [`atelie/README.md`](atelie/README.md).
